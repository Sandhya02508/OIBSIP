# 📢 Advertising Sales Prediction using Machine Learning

![Python](https://img.shields.io/badge/Python-3.x-blue)
![Machine Learning](https://img.shields.io/badge/Machine%20Learning-Project-green)

A Machine Learning project that analyzes advertising data and predicts sales based on different advertising channels using regression techniques.

---

## 📌 Project Overview

This project focuses on analyzing advertising datasets to understand the relationship between marketing spend and product sales. It demonstrates how data analysis and machine learning can be used to generate business insights and accurate predictions.

---

## 🎯 Problem Statement

Businesses invest in multiple advertising channels such as TV, Radio, and Newspaper. The goal of this project is to build a model that can predict sales based on advertising expenditure across these channels.

---

## 📊 Dataset Information

* Dataset contains advertising and sales data

* Features include:

  * TV Advertising Budget
  * Radio Advertising Budget
  * Newspaper Advertising Budget

* Target variable:

  * Sales

---

## ⚙️ Steps Involved

### 1. Data Loading & Understanding

* Loaded dataset using Pandas
* Explored dataset structure and summary

### 2. Data Cleaning

* Checked for missing values
* Ensured data consistency

### 3. Exploratory Data Analysis (EDA)

* Visualized relationships between advertising channels and sales
* Used scatter plots, heatmaps, and pairplots

### 4. Feature Engineering

* Selected important features
* Prepared data for regression modeling

### 5. Model Building

* Applied **Linear Regression** model

### 6. Model Evaluation

* Split dataset into training and testing sets
* Evaluated using:

  * MAE (Mean Absolute Error)
  * MSE (Mean Squared Error)
  * R² Score

---

## 📈 Results

🚀 **Model Performance:**

* MAE: 1.4607
* MSE: 3.1740
* R² Score: 0.8994

✅ **Accuracy: ~89.94%**

The model shows strong performance in predicting sales based on advertising budgets.

---

## 📸 Output

The model predicts sales based on given advertising inputs.

**Example Prediction:**

* Input: TV, Radio, Newspaper budgets
* Output: Predicted Sales
