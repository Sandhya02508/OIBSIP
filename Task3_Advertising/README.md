# Task 3 - Advertising Analysis

This project contains data analysis and visualization on Advertising data using Python and Google Colab.

## 📌 Project Overview
The goal of this project is to analyze advertising datasets and understand the relationship between advertisement spending and sales.

## 🛠 Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn

## 📂 Files Included
- `Sandhya_Task3.ipynb` → Main Google Colab notebook
- `README.md` → Project documentation

## 📊 Features
- Data Cleaning
- Data Visualization
- Advertising Analysis
- Sales Trend Insights
## 📈 Model Performance

The regression model achieved strong prediction performance on the advertising dataset.

- MAE: 1.4607
- MSE: 3.1740
- R² Score: 0.8994

### ✅ Accuracy
The model achieved approximately **89.94% accuracy** based on the R² Score.

The notebook provides graphical insights and analysis based on advertising datasets.
