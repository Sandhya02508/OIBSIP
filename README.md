This repository contains all the projects completed during the **Oasis Infobyte Data Science Internship (OIBSIP)**.
These projects demonstrate skills in **data analysis, machine learning, and data visualization**.

---

## 📌 Internship Overview

The internship focused on real-world data science problems including:

* Regression Models
* Classification Models
* Data Analysis & Visualization
* Model Evaluation

---

## 📂 Projects Included

### 🚗 Task 1: Car Price Prediction

* Built a regression model to predict car prices
* Algorithm: Random Forest Regressor
* 📈 Accuracy: **96.21%**

---

### 📧 Task 2: Email Spam Detection

* Classified emails as spam or not spam
* Algorithm: Machine Learning Classification
* 📈 Accuracy: **97.48%**

---

### 📢 Task 3: Advertising Sales Prediction

* Analyzed advertising data to predict sales
* Algorithm: Linear Regression
* 📈 Accuracy: **89.94%**

---

### 📉 Task 4: Unemployment Analysis & Prediction

* Analyzed unemployment trends and predicted rates
* Algorithm: Random Forest Regressor
* 📈 Accuracy: **89.94%**

---

### 🌸 Task 5: Iris Flower Classification

* Classified iris flowers into species
* Algorithm: Classification Models
* 📈 Accuracy: **96%**
