# Task 4 - Unemployment Analysis and Prediction

This project focuses on analyzing unemployment trends in India and predicting unemployment rates using Machine Learning techniques.

## 📌 Project Overview
The project combines unemployment datasets, performs data preprocessing, visualization, and applies a Random Forest Regressor model for unemployment prediction.

## 🛠 Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## 🤖 Machine Learning Model
- Random Forest Regressor

## 📊 Features
- Data Cleaning
- Data Preprocessing
- Feature Engineering
- Unemployment Trend Analysis
- Machine Learning Prediction
- Model Evaluation

## 📈 Model Performance
- MAE: 1.4607
- MSE: 3.1740
- R² Score: 0.8994

### ✅ Accuracy
The model achieved approximately **89.94% accuracy** based on the R² Score.

## 🚀 Output
The project provides visual insights and predictive analysis of unemployment rates using machine learning.
